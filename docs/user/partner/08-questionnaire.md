# Анкета партнёра

Статус: draft

## Назначение

В этом разделе партнёр заполняет регистрационную анкету, если она требуется платформой.

## Где находится

Кабинет партнёра → Анкета

## Что такое анкета

Анкета — это набор вопросов, которые партнёр заполняет в своём кабинете.

Состав анкеты настраивается в системе и может отличаться со временем.

## Зачем заполнять анкету

По текущей реализации незаполненная анкета влияет на доступ к кабинету.

Если анкета не завершена, партнёра автоматически переводят на страницу анкеты. До заполнения доступны только:

- страница анкеты;
- страница профиля.

## Какие данные могут запрашиваться

Подтверждены типы полей:

- текст;
- многострочный текст;
- выбор одного варианта;
- выбор нескольких вариантов;
- чекбокс;
- radio.

Точный набор вопросов зависит от текущей активной анкеты.

## Что может быть недоступно без анкеты

Подтверждено, что при незавершённой анкете партнёр не может свободно пользоваться остальными страницами кабинета.

## Что видит партнёр

- заголовок анкеты;
- описание анкеты, если оно задано;
- список полей;
- отметку обязательных полей;
- сообщения об ошибках валидации;
- кнопку сохранения ответов.

## Как заполнить анкету

### Заполнить анкету впервые

1. Откройте страницу анкеты.
2. Заполните все обязательные поля.
3. Проверьте ответы.
4. Нажмите кнопку сохранения.

**Результат:** ответы сохраняются, а анкета считается заполненной, если обязательные поля не пропущены.

## Как изменить ответы

По текущей реализации ответы можно редактировать и сохранять повторно.

### Обновить ответы анкеты

1. Откройте страницу анкеты или перейдите туда из профиля.
2. Измените нужные значения.
3. Сохраните форму ещё раз.

**Результат:** новые ответы записываются в систему.

## Основные действия

### Исправить ошибки в обязательных полях

1. Нажмите сохранение.
2. Посмотрите сообщения об ошибках под полями.
3. Заполните пропущенные или некорректные значения.
4. Сохраните анкету повторно.

**Результат:** анкета проходит проверку и сохраняется.

### Вернуться в кабинет после заполнения

1. Убедитесь, что сохранение прошло успешно.
2. Если анкета была обязательной при первом входе, дождитесь возврата в кабинет.

**Результат:** открывается обычный доступ к разделам партнёра.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Вопрос | Текст вопроса анкеты | Для понимания, какие данные нужно указать |
| Тип поля | Формат ответа | Для правильного заполнения |
| Обязательное поле | Поле нельзя пропустить | Используется при первой и повторной отправке |
| Варианты ответа | Набор допустимых значений | Для полей выбора |

## Статусы

Отдельная пользовательская таблица статусов анкеты не подтверждена.

Практически важны два состояния:

| Статус | Что означает |
|---|---|
| Не заполнена | Анкета ещё не завершена |
| Заполнена | Обязательные ответы сохранены |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Анкета не заполнена | Откройте страницу анкеты и проверьте обязательные поля |
| Не все обязательные поля заполнены | Исправьте поля с ошибками и сохраните снова |
| Нет доступа к офферам | Проверьте, завершена ли анкета |
| Ответы нужно изменить | Откройте анкету из профиля и сохраните обновлённые ответы |
| Администратор просит дополнить данные | Вернитесь в анкету и добавьте недостающую информацию |

## Ожидаемый результат

После работы с разделом партнёр должен:

- заполнить обязательные данные;
- открыть доступ к рабочим разделам кабинета;
- понимать, где изменить ответы позже.
