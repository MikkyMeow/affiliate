# Tracking-ссылки

Статус: draft

## Назначение

В этом разделе партнёр получает личную tracking-ссылку для оффера и использует её для отправки трафика так, чтобы клики и конверсии правильно связывались между собой.

## Где находится

Кабинет партнёра → Карточка оффера

## Что такое tracking-ссылка

Tracking-ссылка — это специальная ссылка трекера, через которую должен проходить трафик партнёра.

Именно она нужна, чтобы платформа могла:

- зафиксировать клик;
- связать клик с конкретным оффером;
- понять, какой партнёр привёл трафик;
- позже связать конверсию с этим кликом.

## Зачем использовать tracking-ссылку

Без tracking-ссылки система не сможет корректно учитывать:

- клики;
- конверсии;
- выплаты;
- статистику по офферу;
- статистику по партнёру.

Если партнёр отправляет трафик напрямую на посадочную страницу без этой ссылки, клик и конверсия могут не попасть в кабинет.

## Что видит партнёр

- базовый адрес трекера на dashboard;
- личную ссылку в карточке оффера;
- кнопку `Скопировать`;
- кнопку `Открыть`.

## Как получить ссылку

Tracking-ссылка доступна только в карточке оффера при полном доступе.

### Получить tracking-ссылку

1. Откройте список офферов.
2. Перейдите в карточку нужного оффера.
3. Убедитесь, что оффер активен и у вас уровень доступа `full`.
4. Найдите блок `Личная ссылка`.
5. Скопируйте ссылку кнопкой `Скопировать`.

**Результат:** у вас есть личная ссылка, которую можно использовать для запуска трафика.

## Из чего состоит tracking-ссылка

По подтверждённой реализации ссылка строится на базе адреса трекера и пути `/click`.

Подтверждённый шаблон:

```txt
{TRACKING_BASE_URL}/click?offerId={offerId}&affiliateId={affiliateId}
```

Где:

- `offerId` — идентификатор оффера;
- `affiliateId` — идентификатор партнёра.

Точный публичный домен трекера зависит от окружения проекта.

## Click ID

`click id` — это уникальный идентификатор клика, который создаётся после перехода пользователя по tracking-ссылке.

Он нужен, чтобы:

- найти клик в системе;
- связать конверсию с конкретным переходом;
- передать идентификатор дальше в цепочку трекинга;
- сравнить клик и postback.

Если click id потерян, изменён или не дошёл до рекламодателя, конверсия может не связаться с кликом.

## Что нельзя менять в ссылке

В tracking-ссылке нельзя:

- удалять служебные параметры;
- менять `offerId`;
- менять `affiliateId`;
- использовать ссылку другого партнёра;
- вручную ломать формат URL;
- отправлять трафик на оффер без доступа;
- использовать старую ссылку, если условия оффера изменились и нужна новая;
- вручную менять redirect, если это не предусмотрено интерфейсом.

Если вы меняете обязательные параметры, система может:

- не записать клик;
- не связать клик с конверсией;
- отнести трафик не к тому офферу;
- не отнести трафик к вашему аккаунту.

## Как проверить ссылку

### Проверить, что ссылка рабочая

1. Скопируйте ссылку из карточки оффера.
2. Откройте её в новой вкладке через кнопку `Открыть` или вручную.
3. Убедитесь, что происходит переход на целевой URL или допустимый fallback.
4. После теста проверьте раздел [Клики](./05-clicks.md).

**Результат:** ссылка открывается, а тестовый переход фиксируется как клик.

### Проверить, что ссылка не устарела

1. Откройте карточку оффера.
2. Сравните текущую ссылку с той, которую вы используете в рекламе.
3. Если оффер, доступ или условия изменились, обновите ссылку.

**Результат:** в работе используется актуальная версия tracking-ссылки.

## Основные действия

### Скопировать ссылку для запуска

1. Откройте карточку оффера.
2. Убедитесь, что оффер доступен и ссылка видна.
3. Нажмите `Скопировать`.

**Результат:** готовая tracking-ссылка сохранена в буфере обмена.

### Протестировать переход

1. Нажмите `Открыть` в блоке ссылки.
2. Убедитесь, что открывается корректная посадочная страница.
3. Проверьте, что в разделе кликов появился новый клик.

**Результат:** можно убедиться, что ссылка технически работает.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Личная ссылка | Персональная tracking-ссылка партнёра | Для запуска трафика |
| Target URL | Основной адрес назначения | Для проверки конечной посадочной |
| Fallback URL | Запасной адрес | Если он предусмотрен оффером |
| Preview URL | Ссылка для предпросмотра | Для ручной проверки посадочной |
| offerId | ID оффера | Используется внутри tracking-ссылки |
| affiliateId | ID партнёра | Используется внутри tracking-ссылки |

## Почему конверсия может не появиться

Основные причины:

- пользователь не совершил целевое действие;
- рекламодатель не отправил postback;
- postback отправлен с ошибкой;
- postback не содержит нужный click id;
- click id был изменён или потерян;
- оффер был недоступен на момент отправки трафика;
- GEO не подходит под условия оффера;
- клик не зафиксировался из-за неправильной ссылки;
- используется старая ссылка;
- конверсия ещё обрабатывается;
- конверсия была отклонена.

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Ссылка не открывается | Проверьте, что ссылка скопирована полностью и оффер ещё активен |
| Клик не появляется | Проверьте формат ссылки, `offerId`, `affiliateId` и факт реального перехода через трекер |
| Клик есть, но конверсии нет | Проверьте целевое действие, click id, postback и ограничения оффера |
| Рекламодатель не получил click id | Проверьте, не потерялся ли идентификатор в цепочке редиректа |
| Postback не связался с кликом | Проверьте, что был передан правильный click id и он не был изменён |
| Партнёр использует старую ссылку | Скопируйте актуальную ссылку из текущей карточки оффера |
| Партнёр льёт трафик на выключенный оффер | Остановите трафик и проверьте статус оффера |
