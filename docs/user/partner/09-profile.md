# Профиль партнёра

Статус: draft

## Назначение

В профиле партнёр проверяет свои данные, обновляет Telegram и смотрит сохранённые ответы анкеты.

## Где находится

Кабинет партнёра → Профиль

## Что видит партнёр

- название партнёра;
- public ID;
- email;
- статус партнёра;
- поле Telegram;
- ответственного менеджера;
- блок с ответами анкеты;
- ссылку на редактирование анкеты.

## Настройки профиля

По текущей реализации подтверждено редактирование только поля `Telegram`.

### Обновить Telegram

1. Откройте раздел `Профиль`.
2. Введите или исправьте username без лишних символов.
3. Нажмите `Сохранить Telegram`.

**Результат:** Telegram обновляется в профиле.

## Основные действия

### Проверить свои данные

1. Откройте профиль.
2. Сверьте название партнёра, public ID и email.
3. Проверьте статус аккаунта.

**Результат:** вы понимаете, под каким аккаунтом работаете и активен ли он.

### Открыть ответы анкеты

1. Пролистайте профиль до блока `Ответы анкеты`.
2. Проверьте сохранённые ответы.
3. Если нужно, перейдите по ссылке `Редактировать анкету`.

**Результат:** можно быстро сверить или обновить регистрационные данные.

### Связаться с менеджером

1. Откройте блок `Ответственный менеджер`.
2. Проверьте имя и email менеджера.
3. Используйте эти данные, если нужно уточнить доступ или условия.

**Результат:** понятно, к кому обращаться по рабочим вопросам.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Название | Имя партнёра в системе | Для проверки рабочего аккаунта |
| Public ID | Публичный идентификатор | Для сверки в отчётах и коммуникации |
| Email | Контактный адрес | Для подтверждения учётной записи |
| Статус | Активен аккаунт или нет | Для понимания, доступен ли рабочий кабинет |
| Telegram | Контакт для связи | Можно обновить в интерфейсе |
| Ответственный менеджер | Назначенный менеджер | Для рабочих вопросов по офферам |
