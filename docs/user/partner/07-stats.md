# Статистика

Статус: draft

## Назначение

В этом разделе партнёр смотрит сводные показатели по своему трафику и доходу.

## Где находится

Кабинет партнёра → Статистика

## Что такое статистика

Статистика собирает в одном месте:

- клики;
- конверсии по статусам;
- pending payout;
- approved payout;
- разбивку по офферам.

Это основной раздел для регулярного контроля результата по трафику.

## Что видит партнёр

- карточки с ключевыми показателями;
- кнопку обновления статистики;
- кнопку обновления списка офферов;
- таблицу `По офферам`;
- ссылки назад в кабинет партнёра.

## Статистика по офферам

В таблице по офферам подтверждены:

- название оффера;
- `offerId`;
- клики;
- всего конверсий;
- `approved`;
- `pending`;
- `rejected`;
- `approved payout`;
- `pending payout`.

Разбивка помогает понять:

- какие офферы приносят больше подтверждённых выплат;
- где много кликов, но мало конверсий;
- где накопилось много `pending`;
- по каким офферам высокий объём отклонений.

## Основные метрики

| Метрика | Что означает |
|---|---|
| Клики | Общее число кликов по вашим ссылкам |
| Conversions total | Общее число конверсий |
| Conversions approved | Подтверждённые конверсии |
| Conversions pending | Конверсии на проверке |
| Conversions rejected | Отклонённые конверсии |
| Pending payout | Сумма выплат в статусе `pending` |
| Approved payout | Подтверждённая сумма выплат |

## Основные действия

### Обновить статистику

1. Откройте раздел `Статистика`.
2. Нажмите `Обновить статистику`.
3. Дождитесь обновления карточек и таблицы.

**Результат:** на странице показываются актуальные показатели.

### Обновить названия офферов в разбивке

1. Если в таблице показываются только `offerId`, нажмите `Обновить офферы`.
2. Дождитесь повторной загрузки списка.
3. Проверьте таблицу снова.

**Результат:** статистика по офферам сопоставляется с их названиями.

### Найти проблемный оффер

1. Откройте таблицу `По офферам`.
2. Сравните клики, `approved`, `pending`, `rejected`.
3. Перейдите в карточку оффера или в клики и конверсии для диагностики.

**Результат:** можно понять, какой оффер требует внимания.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Offer | Название оффера | Для чтения разбивки по кампаниям |
| Offer ID | Идентификатор оффера | Для точной сверки с другими разделами |
| Clicks | Количество кликов | Для оценки объёма трафика |
| Всего | Все конверсии по офферу | Для общей оценки результата |
| Approved | Подтверждённые конверсии | Для оценки реального результата |
| Pending | Конверсии на проверке | Для контроля ожидаемых выплат |
| Rejected | Отклонённые конверсии | Для контроля качества трафика |
| Approved payout | Подтверждённая выплата | Для контроля дохода |
| Pending payout | Выплата, которая ещё на проверке | Для прогноза дохода |

## Расхождения между кликами и конверсиями

Нормально, если кликов больше, чем конверсий. Это не всегда ошибка.

Причины:

- не каждый пользователь совершает целевое действие;
- конверсия может быть ещё не обработана;
- часть конверсий может быть отклонена;
- часть трафика может не подходить по GEO или другим условиям.

## Почему данные могут отличаться

Расхождения возможны из-за:

- разницы по времени обновления систем;
- разной логики учёта кликов;
- потери или ошибки в click id;
- различий между сырыми кликами и подтверждёнными конверсиями;
- отклонённых конверсий;
- разных ролей и уровней доступа в системе.

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Кликов больше, чем в другой системе | Сравните период, формат tracking-ссылки и способ учёта переходов |
| Конверсий меньше, чем ожидалось | Проверьте целевое действие, postback, GEO и отклонения |
| Доход за период не совпадает | Сравните `pending payout` и `approved payout`, проверьте статусы |
| Статистика не обновилась сразу | Используйте ручное обновление и учитывайте возможную задержку обработки |
| Разные роли видят разные цифры | Партнёр видит только свои данные и доступные ему офферы |

## Ожидаемый результат

После работы с разделом партнёр должен понимать:

- сколько кликов и конверсий он получил;
- какой доход уже подтверждён;
- какие офферы дают лучший результат;
- где есть просадка по качеству трафика или подтверждению конверсий.
