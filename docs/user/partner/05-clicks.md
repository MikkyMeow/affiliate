# Клики

Статус: draft

## Назначение

В этом разделе партнёр смотрит зафиксированные переходы по своим tracking-ссылкам.

## Где находится

Кабинет партнёра → Клики

## Что такое клик

Клик — это переход пользователя по вашей tracking-ссылке, который был записан системой.

Клик нужен, чтобы:

- понимать объём трафика;
- сравнивать трафик с конверсиями;
- искать проблемные переходы;
- связывать конверсию с источником трафика.

## Что видит партнёр

- таблицу кликов;
- пагинацию;
- кнопку `Обновить данные`;
- строки с `click id`, `offer id`, `sub1`, `device`, датой создания.

## Список кликов

Текущая страница показывает историю реальных переходов по вашим ссылкам.

В таблице нет расширенной карточки клика. Диагностика строится по строкам списка и по сравнению с конверсиями.

## Основные поля клика

| Поле | Что означает | Когда используется |
|---|---|---|
| Click ID | Уникальный идентификатор клика | Для поиска конкретного перехода и сверки с конверсией |
| Offer ID | Идентификатор оффера | Для проверки, в какой оффер ушёл трафик |
| Sub1 | Дополнительная метка трафика | Для простой сегментации источников |
| Device | Устройство пользователя | Для базовой диагностики качества трафика |
| Создан | Дата и время клика | Для сверки периода и поиска тестовых переходов |

## Как диагностировать проблему по клику

### Проверить, записался ли тестовый переход

1. Откройте tracking-ссылку из карточки оффера.
2. Перейдите в раздел `Клики`.
3. Обновите данные и найдите новый переход по времени.

**Результат:** видно, дошёл ли переход до системы.

### Проверить связь клика с оффером

1. Найдите нужный `click id`.
2. Сверьте `offer id` в строке.
3. Сравните данные с той ссылкой, которую вы запускали.

**Результат:** можно понять, не был ли трафик отправлен не в тот оффер.

### Сравнить клик с конверсией

1. Скопируйте `click id` из строки клика.
2. Откройте раздел [Конверсии](./06-conversions.md).
3. Сверьте, появилась ли конверсия по этому переходу.

**Результат:** становится понятно, дошла ли цепочка от клика до конверсии.

## Основные действия

### Обновить список кликов

1. Откройте раздел `Клики`.
2. Нажмите `Обновить данные`.
3. Дождитесь перезагрузки таблицы.

**Результат:** вы видите актуальный список переходов.

### Перейти между страницами

1. Используйте кнопки `Назад` и `Вперёд`.
2. Перелистните список до нужного периода.
3. Найдите нужную строку по времени и `click id`.

**Результат:** можно просмотреть историю кликов постранично.
