# Карточка оффера

Статус: draft

## Назначение

В этом разделе партнёр проверяет конкретный оффер перед запуском трафика: доступ, ссылки, цели, ставки и ограничения.

## Где находится

Кабинет партнёра → Офферы → Карточка оффера

## Что такое карточка оффера

Карточка оффера показывает всю доступную информацию по одной кампании.

Если доступ полный, партнёр видит:

- описание;
- target URL;
- fallback URL;
- preview URL;
- tracking-ссылку;
- цели и выплаты;
- ограничения по запуску.

Если доступ неполный, часть информации скрыта до одобрения.

## Что видит партнёр

- название оффера;
- категорию;
- статус оффера;
- доступность: `public`, `on_request`, `private`;
- уровень доступа: `full`, `restricted`, `none`;
- предупреждение или причину ограничения, если она есть;
- описание оффера;
- блок ссылок;
- блок tracking-ссылки;
- блок целей и выплат.

## Условия оффера

В карточке подтверждены базовые условия:

- статус оффера;
- доступность;
- уровень доступа;
- описание;
- тип таргетинга: только согласованные GEO или свободный трафик.

## Цели

Если доступ `full`, партнёр видит список целей.

Для цели подтверждены поля:

- название;
- тип цели;
- выплата;
- валюта;
- признак `Default`;
- признак `Лимит достигнут`.

Типы целей, подтверждённые интерфейсом:

- `CPL`;
- `CPA`;
- `CPC`.

## Ограничения

Проверьте перед запуском:

- активен ли оффер;
- есть ли полный доступ;
- не достигнут ли лимит по нужной цели;
- нет ли причины отказа или ограничения;
- не требует ли оффер отдельного согласования GEO.

## Tracking URL

Если доступ `full`, партнёр видит личную tracking-ссылку в формате:

`{tracking_base}/click?offerId={offerId}&affiliateId={affiliateId}`

По кнопке можно:

- скопировать ссылку;
- открыть ссылку в новой вкладке.

Если `affiliateId` не готов или доступ неполный, ссылка может не показываться.

## Что проверить перед запуском трафика

1. Статус оффера должен быть `active`.
2. Уровень доступа должен быть `full`.
3. Нужная цель должна быть понятна и активна.
4. Выплата по цели должна соответствовать вашим ожиданиям.
5. GEO должно подходить под условия оффера.
6. Tracking-ссылка должна быть сгенерирована именно для вашего аккаунта.
7. При наличии лимитов убедитесь, что лимит не достигнут.

## Основные действия

### Открыть детали оффера

1. Перейдите в список офферов.
2. Выберите нужную кампанию.
3. Откройте карточку оффера.

**Результат:** на экране появляется полная или ограниченная информация по офферу.

### Проверить, можно ли запускать трафик

1. Проверьте статус оффера.
2. Проверьте уровень доступа.
3. Если доступ `full`, проверьте цели и tracking-ссылку.

**Результат:** становится понятно, готов ли оффер к запуску.

### Скопировать tracking-ссылку

1. Откройте блок `Личная ссылка`.
2. Нажмите `Скопировать`.
3. Используйте ссылку в своей рекламной системе или трекере.

**Результат:** личная tracking-ссылка сохранена для запуска трафика.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Название оффера | Имя кампании | Для идентификации оффера |
| Категория | Категория кампании | Для понимания типа оффера |
| Статус | Активен или на паузе | Для решения, можно ли запускать трафик |
| Доступность | `public`, `on_request`, `private` | Для понимания модели доступа |
| Уровень доступа | `full`, `restricted`, `none` | Для понимания, доступна ли ссылка и цели |
| Target URL | Основной URL назначения | Для проверки, куда идёт трафик |
| Fallback URL | Запасной URL | Используется, если он предусмотрен |
| Preview URL | Ссылка для предварительной проверки | Помогает посмотреть посадочную |
| Payout | Выплата по цели | Для оценки дохода |
| Default | Основная цель по умолчанию | Полезно, если у оффера несколько целей |
| Лимит достигнут | Ограничение по цели | Требует проверки перед запуском |

## Статусы

| Статус | Что означает |
|---|---|
| active | Оффер активен |
| inactive | Оффер неактивен |
| full | Полный доступ к офферу |
| restricted | Ограниченный доступ |
| none | Доступ не выдан |
| pending | Заявка на доступ ожидает рассмотрения |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Непонятно, какая цель оплачивается | Проверьте блок `Цели и выплаты`, признак `Default` и название цели |
| Ставка отличается от ожидаемой | Смотрите `payout` именно в карточке оффера, а не в старых материалах |
| GEO не подходит | Проверьте, не стоит ли режим `Только согласованные GEO` |
| Ссылка неактивна | Проверьте статус оффера, уровень доступа и наличие `affiliateId` |
| Доступ к офферу не выдан | Проверьте уровень доступа и возможность отправить заявку |
| Условия изменились | Используйте только текущие данные из карточки оффера и обновите ссылку при необходимости |
