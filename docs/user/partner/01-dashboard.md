# Dashboard партнёра

Статус: draft

## Назначение

В этом разделе партнёр быстро смотрит свои основные показатели: клики, конверсии, выплаты и разбивку по офферам.

## Где находится

Кабинет партнёра → Dashboard

## Что видит партнёр

- блок с кнопками обновления статистики и данных;
- быстрые ссылки на разделы `Офферы`, `Статистика`, `Клики`, `Конверсии`;
- карточку профиля партнёра с названием, email, affiliate ID и статусом;
- блок с базовым tracking URL и примером ссылки;
- карточки с ключевыми метриками;
- таблицу с разбивкой показателей по офферам;
- список доступных офферов с быстрыми действиями.

## Основные метрики

| Метрика | Что означает | Как использовать |
|---|---|---|
| Подтв. выплаты, ₽ | Сумма по конверсиям в статусе `approved` | Показывает подтверждённый доход за видимый период |
| Ожидают выплату, ₽ | Сумма по конверсиям в статусе `pending` | Помогает понять, сколько денег ещё на проверке |
| Approved conversions | Количество подтверждённых конверсий | Используйте как основной показатель результата |
| Pending conversions | Количество конверсий, которые ещё не подтверждены | Если значение растёт слишком долго, нужно проверять причины |
| Rejected conversions | Количество отклонённых конверсий | Если их много, проверьте качество трафика и условия оффера |
| Клики | Количество кликов по вашим ссылкам | Помогает сравнить объём трафика с конверсиями |

## Доход

На dashboard подтверждённый доход показан в карточке `Подтв. выплаты, ₽`.

Сумма в карточке `Ожидают выплату, ₽` не является финальной выплатой. Это только конверсии, которые ещё ждут проверки.

Если сумма меньше ожидаемой, проверьте:

- нет ли большого числа `pending`;
- нет ли отклонённых конверсий;
- соответствует ли офферу нужная цель;
- не менялись ли условия оффера.

## Клики

Карточка `Клики` показывает общее число переходов по вашим tracking-ссылкам.

Клики полезно сравнивать с:

- количеством конверсий;
- разбивкой по офферам;
- данными из раздела [Клики](./05-clicks.md).

## Конверсии

Dashboard показывает три ключевых статуса:

- `approved` — подтверждённые;
- `pending` — ожидают проверки;
- `rejected` — отклонённые.

Подробный список конверсий находится в разделе [Конверсии](./06-conversions.md).

## Статистика по офферам

В таблице по офферам партнёр видит:

- название оффера;
- внутренний `offerId`;
- клики;
- всего конверсий;
- `approved`;
- `pending`;
- `rejected`;
- `approved payout`;
- `pending payout`.

Эта таблица помогает быстро понять:

- какой оффер даёт лучший результат;
- где есть клики, но нет конверсий;
- по каким офферам зависло много `pending`;
- где вырос процент отклонений.

## Статусы конверсий

| Статус | Что означает |
|---|---|
| pending | Конверсия зафиксирована, но ещё не подтверждена |
| approved | Конверсия подтверждена |
| rejected | Конверсия отклонена |

## Что видит партнёр в списке офферов на dashboard

В нижней части dashboard показывается список доступных кампаний.

Для оффера могут быть доступны действия:

- открыть карточку оффера;
- скопировать tracking-ссылку, если доступ полный;
- запросить доступ, если оффер работает по модели `on_request`.

## Основные действия

### Обновить dashboard

1. Откройте dashboard партнёра.
2. Нажмите `Обновить статистику`, если нужно обновить показатели.
3. Нажмите `Обновить данные`, если нужно заново загрузить профиль и офферы.

**Результат:** на экране загружаются актуальные данные.

### Быстро проверить, какие офферы работают лучше

1. Найдите таблицу с разбивкой по офферам.
2. Сравните клики, количество конверсий и подтверждённые выплаты.
3. Откройте оффер с лучшими или проблемными показателями для проверки условий.

**Результат:** вы понимаете, на какие офферы стоит масштабировать трафик, а какие нужно перепроверить.

### Перейти к деталям по кликам или конверсиям

1. Используйте быстрые ссылки `Клики`, `Конверсии` или `Статистика`.
2. Откройте нужный раздел.
3. Сверьте общий показатель с детальными строками.

**Результат:** можно быстро перейти от общей картины к диагностике конкретной проблемы.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Название | Имя партнёра | Для проверки, под каким аккаунтом вы работаете |
| Email | Контактный email партнёра | Для сверки учётных данных |
| Affiliate ID | Идентификатор партнёра в системе | Используется в tracking-ссылке |
| Статус | Активен партнёр или нет | Если статус неактивный, доступ к работе может быть ограничен |
| Базовый tracking URL | Базовый адрес трекера | Используется как ориентир для работы со ссылками |
| Пример ссылки | Пример tracking-ссылки с параметрами | Помогает понять формат ссылки |

## Как понять, что есть проблема

Обратите внимание на такие признаки:

- кликов много, а `approved` и `pending` нет;
- `pending` долго не меняются;
- `rejected` слишком много;
- по офферу есть клики, но нет `approved payout`;
- доход по офферу резко упал по сравнению с прошлым периодом;
- оффер исчез из списка или больше не даёт ссылку.

Если проблема уже видна на dashboard, дальше обычно нужно открыть:

- [Офферы](./02-offers.md);
- [Клики](./05-clicks.md);
- [Конверсии](./06-conversions.md);
- [Статистика](./07-stats.md).

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Клики есть, конверсий нет | Проверьте tracking-ссылку, доступ к офферу, GEO, целевое действие и факт отправки postback |
| Конверсии есть, но они pending | Это не финальная выплата. Проверьте, не находится ли трафик ещё на проверке |
| Доход меньше ожидаемого | Сравните `approved payout` и `pending payout`, проверьте отклонённые конверсии и актуальные ставки оффера |
| Данные за период выглядят неполными | Нажмите обновление данных и проверьте, не было ли задержки обновления статистики |
| Статистика отличается от данных рекламной сети | Сравните click id, целевое действие, статусы конверсий и условия атрибуции |

## Ожидаемый результат

После работы с dashboard партнёр должен быстро понять:

- сколько у него кликов;
- сколько конверсий подтверждено, ожидает проверки и отклонено;
- какой доход уже подтверждён;
- какие офферы приносят результат;
- где нужно разбираться с качеством трафика или настройкой ссылок.
