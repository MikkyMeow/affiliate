# Advertisers

Статус: draft

## Назначение

В этом разделе администратор управляет рекламодателями: создаёт их, редактирует данные, назначает менеджеров, смотрит ответы анкеты и при необходимости сбрасывает пароль.

## Где находится

Админ-панель → Рекламодатели

## Что видит администратор

На экране списка есть:
- таблица рекламодателей;
- поиск;
- фильтры по менеджеру и статусу;
- сортировка;
- пагинация;
- кнопка создания нового рекламодателя.

В карточке рекламодателя есть:
- основные данные;
- статус;
- email и Telegram;
- ответственный менеджер;
- ответы анкеты;
- внутренняя заметка;
- действие сброса пароля.

## Список рекламодателей

В списке подтверждены такие данные:
- public ID;
- название;
- email;
- Telegram, если есть;
- статус;
- ответственный менеджер;
- даты создания и обновления.

## Основные действия

### Найти рекламодателя

1. Откройте раздел `Рекламодатели`.
2. Используйте поиск.
3. При необходимости добавьте фильтр по менеджеру или статусу.

**Результат:** в таблице останутся только подходящие записи.

### Создать рекламодателя

1. Нажмите `Создать рекламодателя`.
2. Укажите название.
3. Укажите email.
4. Выберите статус.
5. Сохраните форму.

**Результат:** система создаст рекламодателя и покажет временный пароль один раз.

### Редактировать рекламодателя

1. Откройте карточку рекламодателя.
2. Измените название или статус.
3. Сохраните изменения.

**Результат:** данные рекламодателя обновятся.

### Назначить менеджера

1. Откройте карточку рекламодателя.
2. Выберите ответственного менеджера.
3. Сохраните назначение.

**Результат:** рекламодатель будет закреплён за нужным менеджером.

### Сбросить пароль рекламодателя

1. Откройте карточку рекламодателя.
2. Запустите сброс пароля.
3. Скопируйте временный пароль и передайте его безопасным способом.

**Результат:** рекламодатель получит новый временный пароль. Интерфейс показывает его один раз.

## Создание рекламодателя

Создание рекламодателя доступно только администратору.

Форма создания подтверждена с полями:
- название;
- email;
- статус.

После создания система показывает временный пароль только один раз.

## Редактирование рекламодателя

В карточке подтверждены:
- изменение названия;
- изменение статуса;
- просмотр email и Telegram;
- просмотр ответов анкеты;
- назначение менеджера;
- сохранение внутренней заметки;
- сброс пароля.

## Связь с пользователем

У рекламодателя есть пользовательская учётная запись с отдельным кабинетом.

Это важно:
- рекламодатель входит в свой кабинет по email;
- до заполнения обязательной анкеты часть функций может быть ограничена;
- в админке видны ответы анкеты и служебные поля, которых нет в публичном кабинете.

## Назначение менеджеров

Менеджер назначается в карточке рекламодателя.

Это удобно, когда нужно:
- закрепить клиента за конкретным сотрудником;
- передать коммуникацию другому менеджеру;
- фильтровать список рекламодателей по ответственному.

## Как рекламодатель использует кабинет

По текущей реализации рекламодатель работает в своём кабинете с разделами:
- обзор;
- офферы;
- статистика;
- postbacks;
- финансы;
- профиль;
- анкета, если она ещё не заполнена.

## Связанные офферы

Оффер создаётся с привязкой к рекламодателю.

Поэтому при работе с рекламодателем полезно сразу проверять:
- есть ли у него активные офферы;
- настроены ли цели;
- корректен ли postback token и цели у офферов;
- есть ли статистика по связанным офферам.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Public ID | Короткий публичный идентификатор рекламодателя | Для поиска и сверки |
| Название | Название рекламодателя | В списках, карточках и офферах |
| Email | Логин рекламодателя | Для входа и поиска |
| Статус | Активен или неактивен | Для включения или отключения работы |
| Telegram | Контакт рекламодателя, если заполнен | Для связи |
| Ответственный менеджер | Закреплённый менеджер | Для операционного сопровождения |
| Внутренняя заметка | Служебный комментарий | Для внутренней работы команды |

## Фильтры и поиск

В списке подтверждены:
- поиск;
- фильтр по менеджеру;
- фильтр по статусу;
- сортировка;
- размер страницы.

## Статусы

| Статус | Что означает |
|---|---|
| active | Рекламодатель активен |
| inactive | Рекламодатель выключен |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Рекламодатель не видит оффер | Проверьте, привязан ли оффер к этому рекламодателю и активен ли он. |
| Рекламодатель не видит статистику | Проверьте, есть ли связанные клики и конверсии, а также заполнена ли обязательная анкета рекламодателя. |
| Рекламодатель не может проверить postback | Проверьте настройки оффера, цели оффера и наличие корректного postback token. |
| Нужно передать рекламодателя другому менеджеру | Откройте карточку и смените ответственного менеджера. |
| Нужно выдать новый пароль | Используйте сброс пароля в карточке и передайте временный пароль безопасно. |

## Ожидаемый результат

После работы с разделом администратор должен:
- создать рекламодателя и выдать ему доступ;
- закрепить его за менеджером;
- проверить, как он связан с офферами и статистикой;
- быстро решить вопросы по входу и postback.
