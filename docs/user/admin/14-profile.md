## Timezone

Администратор может:
- использовать системный часовой пояс;
- выбрать timezone вручную из списка.

После сохранения timezone обновляется профиль и этот часовой пояс начинает использоваться в интерфейсе, где данные зависят от времени.

## Смена пароля

Смена пароля подтверждена в интерфейсе.

Для этого нужны:
- текущий пароль;
- новый пароль;
- подтверждение нового пароля.

Если подтверждение не совпадает с новым паролем, система не даст отправить форму.

## Как timezone влияет на данные

Timezone влияет на:
- отображение дат и времени;
- интерпретацию периодов в dashboard;
- сверку данных между разными пользователями.

Практически это важно, когда:
- администратор сравнивает статистику с партнёром или рекламодателем;
- в отчётах есть расхождения по дню или часу;
- нужно сопоставить системные события с внешними логами.

## Основные действия

### Изменить часовой пояс

1. Откройте профиль.
2. Выберите `Системный` или конкретный timezone.
3. Сохраните изменение.

**Результат:** интерфейс начнёт использовать новый часовой пояс для отображения дат и времени.

### Сменить пароль

1. Откройте блок смены пароля.
2. Введите текущий пароль.
3. Введите новый пароль и подтверждение.
4. Сохраните форму.

**Результат:** пароль будет обновлён.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Имя | Отображаемое имя пользователя | Для проверки текущей учётной записи |
| Email | Email пользователя | Для проверки логина |
| Роль | Текущая роль | Для понимания уровня доступа |
| Timezone | Часовой пояс пользователя | Для корректного отображения дат и времени |
| Current password | Текущий пароль | Для подтверждения смены пароля |
| New password | Новый пароль | Для обновления доступа |
| Confirm password | Подтверждение нового пароля | Для защиты от ошибки ввода |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Время в отчётах выглядит неверно | Проверьте выбранный timezone и сравните его с системным. |
| Данные по дате отличаются от данных партнёра | Проверьте timezone у администратора и у другой стороны. |
| Не удаётся сменить пароль | Проверьте текущий пароль и совпадение нового пароля с подтверждением. |
| После смены timezone данные всё равно выглядят странно | Проверьте dashboard и другие отчёты после обновления страницы. |

## Ожидаемый результат

После работы с профилем администратор должен:
- понимать, под какой учётной записью он работает;
- использовать правильный timezone;
- поддерживать актуальный пароль для входа.
