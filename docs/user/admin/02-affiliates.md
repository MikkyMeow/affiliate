# Affiliates

Статус: draft

## Назначение

В этом разделе администратор смотрит список партнёров, создаёт новых партнёров, редактирует существующих, назначает менеджера и проверяет внутренние данные по партнёру.

## Где находится

Админ-панель → Партнёры

## Что видит администратор

На экране списка есть:
- таблица партнёров;
- поиск;
- фильтры по менеджеру, статусу и наличию Telegram;
- сортировка;
- пагинация;
- ссылка на создание партнёра;
- переход в карточку редактирования.

В карточке партнёра есть:
- основные данные партнёра;
- статус;
- Telegram, если он указан;
- ответственный менеджер;
- ответы анкеты;
- приватная внутренняя заметка.

## Список партнёров

В списке администратор видит:
- public ID партнёра, если он есть;
- имя или название;
- email;
- Telegram, если он заполнен;
- статус;
- ответственного менеджера;
- даты создания и обновления.

## Основные действия

### Найти партнёра в списке

1. Откройте раздел `Партнёры`.
2. Введите в поиске имя, email или другой доступный идентификатор.
3. При необходимости добавьте фильтры по менеджеру, статусу и Telegram.

**Результат:** в таблице остаются только подходящие партнёры.

### Создать партнёра

1. Нажмите `Создать партнёра`.
2. Заполните имя или название.
3. Укажите email.
4. Выберите статус.
5. Сохраните форму.

**Результат:** новый партнёр появится в списке.

### Редактировать партнёра

1. Откройте карточку партнёра из списка.
2. Измените имя, email или статус.
3. Сохраните изменения.

**Результат:** обновлённые данные сохранятся в карточке партнёра.

### Назначить или сменить менеджера

1. Откройте карточку партнёра.
2. В блоке ответственного менеджера выберите нужного пользователя.
3. Сохраните назначение.

**Результат:** у партнёра появится новый ответственный менеджер.

### Сохранить внутреннюю заметку

1. Откройте карточку партнёра.
2. Введите текст во внутреннее поле заметки.
3. Сохраните изменения.

**Результат:** заметка будет видна только внутри админской части.

## Создание партнёра

Форма создания подтверждена со следующими полями:
- имя / название;
- email;
- статус.

После создания партнёр появляется в списке. Пароль в этой форме не показывается.

## Редактирование партнёра

В карточке редактирования подтверждены такие действия:
- изменить имя;
- изменить email;
- изменить статус;
- назначить или снять ответственного менеджера;
- просмотреть ответы анкеты;
- сохранить внутреннюю заметку.

## Связь с пользователем

У партнёра есть пользовательская учётная запись, связанная с email.

Практически это означает:
- вход в кабинет партнёр делает по email;
- в карточке партнёра администратор работает с бизнес-профилем партнёра;
- часть данных, например анкета и Telegram, может приходить из пользовательского профиля.

## Доступы партнёра

Доступ к офферам настраивается не в списке партнёров, а на стороне оффера и правил доступа.

Проверяйте:
- статус партнёра;
- статус оффера;
- режим видимости оффера;
- выдан ли ручной доступ;
- не скрыт ли оффер для этого партнёра;
- заполнена ли обязательная анкета, если она активна для партнёров.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Public ID | Короткий публичный идентификатор партнёра | Для поиска и сверки в списках и CSV |
| Имя / название | Отображаемое имя партнёра | В списке, карточке и связанных сущностях |
| Email | Логин партнёра и основной контакт | Для входа и поиска партнёра |
| Статус | Активен или неактивен | Когда нужно включить или отключить работу партнёра |
| Telegram | Контакт партнёра, если он заполнен | Для связи и проверки профиля |
| Ответственный менеджер | Менеджер, закреплённый за партнёром | Для операционной работы и маршрутизации вопросов |
| Внутренняя заметка | Приватная информация для команды | Для внутренних комментариев |

## Фильтры и поиск

В списке подтверждены:
- поиск;
- фильтр по менеджеру;
- фильтр по статусу;
- фильтр `hasTelegram`;
- сортировка;
- размер страницы.

## Статусы партнёра

| Статус | Что означает |
|---|---|
| active | Партнёр активен и может работать в кабинете, если нет других ограничений |
| inactive | Партнёр отключён для обычной работы |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Партнёр не может войти | Проверьте email, статус партнёра и статус пользовательской учётной записи. TODO: уточнить, есть ли отдельный экран сброса пароля для партнёра в админке. |
| Партнёр не видит оффер | Проверьте статус оффера, режим видимости, ручной доступ и скрытие оффера для этого партнёра. |
| Партнёр видит оффер, но не может получить ссылку | Проверьте, выдан ли полный доступ к офферу и не находится ли оффер в режиме `on_request` без одобрения. |
| У партнёра нет конверсий | Проверьте, есть ли клики, корректная ли tracking-ссылка и доходят ли postback по нужной цели. |
| Нужно отключить партнёра | Откройте карточку, переведите статус в `inactive` и сохраните изменения. |

## Ожидаемый результат

После работы с разделом администратор должен:
- найти нужного партнёра;
- создать нового партнёра или обновить данные существующего;
- понять, какой менеджер за него отвечает;
- быстро проверить, почему партнёр не видит оффер или не получает конверсии.
