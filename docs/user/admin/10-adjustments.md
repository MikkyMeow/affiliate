# Adjustments

Статус: draft

## Назначение

В этом разделе администратор загружает ручные корректировки через CSV, сначала смотрит preview, потом применяет batch и проверяет результат.

## Где находится

Админ-панель → Корректировки

## Что такое корректировки

Корректировки — это ручное добавление или обновление данных через CSV.

По проекту поддержаны два типа:
- `conversions`;
- `clicks`.

## Когда использовать корректировки

Корректировки нужны, когда:
- рекламодатель передал данные вне обычного postback;
- нужно массово добавить manual-конверсии;
- нужно добавить manual-clicks;
- нужно загрузить пакет исправлений по историческим данным.

## Что видит администратор

На странице подтверждены:
- выбор типа корректировки;
- режим партнёра `single_partner` или `per_row`;
- выбор партнёра, оффера и цели по умолчанию;
- default status;
- загрузка CSV;
- preview batch;
- история batch;
- просмотр деталей batch;
- применение batch после preview.

## Основные действия

### Загрузить CSV на preview

1. Откройте раздел `Корректировки`.
2. Выберите тип: `conversions` или `clicks`.
3. Настройте режим партнёра и значения по умолчанию.
4. Выберите CSV-файл.
5. Запустите preview.

**Результат:** система проверит файл и покажет, какие строки будут применены, а где есть ошибки.

### Применить batch

1. Убедитесь, что preview выглядит правильно.
2. Запустите `Apply`.
3. Дождитесь завершения обработки.

**Результат:** valid-строки будут превращены в manual-clicks или manual-conversions.

### Открыть детали прошлой корректировки

1. Найдите batch в истории.
2. Откройте detail.
3. Проверьте статус batch и диагностику строк.

**Результат:** вы увидите, что именно было загружено и с какими ошибками.

## Импорт CSV

На странице есть примеры CSV для двух типов:

Для конверсий:
- `partner_id`;
- `offer_id`;
- `goal_id`;
- `status`;
- `external_id`;
- `created_at`;
- `comment`.

Для кликов:
- `partner_id`;
- `offer_id`;
- `country`;
- `sub1`;
- `sub2`;
- `ip`;
- `created_at`;
- `comment`.

## Корректировки кликов

При типе `clicks` система создаёт manual-clicks.

Такие записи:
- участвуют в статистике;
- привязаны к batch;
- помечаются как manual source.

## Корректировки конверсий

При типе `conversions` система создаёт manual-conversions.

Для них важно:
- synthetic click не нужен;
- запись хранит прямую связь с партнёром, оффером и целью;
- статус можно задать в CSV или через default status.

## Батчи корректировок

Каждая загрузка создаёт batch.

Для batch подтверждены статусы:
- `previewed`;
- `applied`;
- `failed`.

Batch помогает:
- отделять одну загрузку от другой;
- возвращаться к истории;
- понимать, кто и когда применил корректировку.

## Ошибки импорта

Ошибки обычно видны уже на preview.

Проверяйте:
- формат CSV;
- обязательные поля;
- существование партнёра, оффера и цели;
- корректность статуса;
- корректность дат.

## Ограничения

При работе с корректировками учитывайте:
- preview сам по себе не создаёт клики и конверсии;
- применяются только valid-строки;
- money в CSV не является единственным источником истины для manual-конверсий;
- manual записи влияют на статистику после применения batch;
- для конверсий нужна корректная цель, если она не задаётся по умолчанию.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Type | Тип batch: clicks или conversions | При выборе сценария загрузки |
| Partner mode | Как задаётся партнёр: один на весь файл или в каждой строке | При подготовке CSV |
| Affiliate | Партнёр по умолчанию | Для single-partner режима |
| Offer | Оффер по умолчанию | Когда оффер одинаков для всех строк |
| Goal | Цель по умолчанию | Для конверсий |
| Default status | Статус по умолчанию | Когда статус не берётся из строки |
| Original filename | Имя загруженного файла | Для истории batch |
| Batch status | Состояние batch | Для контроля процесса |

## Статусы

| Статус | Что означает |
|---|---|
| previewed | Preview создан, но batch ещё не применён |
| applied | Batch применён |
| failed | Batch завершился с ошибкой |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| CSV не импортируется | Проверьте формат файла, разделители, обязательные поля и тип batch. |
| Часть строк импортировалась с ошибками | Откройте preview/detail batch и проверьте диагностику строк. |
| Нужно исправить статус конверсий | Используйте корректировки типа `conversions` или меняйте статусы в разделе конверсий, если нужен точечный сценарий. |
| Нужно массово обновить данные | Используйте CSV batch вместо ручного редактирования по одной записи. |
| Импорт повлиял на статистику | Проверьте, что batch применён, и сверяйте изменения через dashboard, клики, конверсии и аудит. |

## Ожидаемый результат

После работы с разделом администратор должен:
- безопасно проверить CSV на preview;
- применить только корректный batch;
- понимать, какие manual-записи были созданы;
- уметь найти историю загрузки позже.
