# Офферы

Статус: draft

## Назначение

В этом разделе рекламодатель смотрит список своих офферов, их текущий статус и базовые параметры. Раздел нужен для навигации по офферам и перехода в карточку конкретного оффера.

## Где находится

Кабинет рекламодателя → Офферы

## Что такое список офферов

Список офферов показывает все офферы, доступные текущему рекламодателю в его кабинете. Это обзорный экран, где можно:

- найти нужный оффер;
- проверить статус;
- посмотреть базовый revenue;
- открыть карточку оффера.

## Какие офферы видит рекламодатель

Рекламодатель видит только свои офферы.

По текущей реализации в списке выводятся:

- `id`;
- `name`;
- `status`;
- `revenueRub`;
- дата создания;
- дата обновления.

Если оффер отсутствует в списке, это может означать, что:

- он не относится к текущему рекламодателю;
- он недоступен по текущим фильтрам;
- доступ к нему ограничен.

## Что видит рекламодатель

- строку поиска по названию;
- фильтр по статусу;
- таблицу офферов;
- пагинацию;
- кнопку перехода в карточку оффера.

## Что можно смотреть

В списке офферов можно смотреть:

- название оффера;
- ID оффера;
- статус;
- revenue;
- дату создания;
- дату последнего обновления.

Для более подробной информации нужно открыть [Карточку оффера](./03-offer-detail.md).

## Что нельзя редактировать

В интерфейсе рекламодателя этот раздел read-only.

Подтверждено, что рекламодатель не редактирует из списка:

- название оффера;
- статус;
- revenue;
- базовые условия оффера.

Если нужно поменять условия оффера, это делается не из кабинета рекламодателя.

## Основные действия

### Найти оффер по названию

1. Откройте раздел `Офферы`.
2. Введите часть названия в поле поиска.
3. Нажмите `Найти`.

**Результат:** список сократится до офферов, которые подходят под поиск.

### Отфильтровать офферы по статусу

1. Откройте выпадающий список `Статус`.
2. Выберите нужный статус.
3. Дождитесь обновления списка.

**Результат:** в таблице останутся офферы с выбранным статусом.

### Открыть карточку оффера

1. Найдите нужный оффер в таблице.
2. Нажмите `Открыть`.
3. Перейдите в карточку оффера.

**Результат:** откроется детальная страница оффера со статистикой и основными параметрами.

### Перейти между страницами списка

1. Пролистайте список до блока пагинации.
2. Нажмите `Назад` или `Вперёд`.
3. Дождитесь загрузки следующей страницы.

**Результат:** откроется нужная страница списка офферов.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Название | Имя оффера | Когда нужно найти конкретный оффер |
| ID | Внутренний идентификатор оффера | Когда нужно сверить оффер с postback, статистикой или поддержкой |
| Статус | Текущее состояние оффера | Когда нужно понять, активен ли оффер |
| Revenue | Базовое значение revenue в списке | Для быстрой сверки условий |
| Создан | Дата создания оффера | Для справки |
| Обновлён | Дата последнего изменения | Когда нужно понять, менялись ли условия или состояние |

## Статусы офферов

| Статус | Что означает |
|---|---|
| `active` | Оффер активен |
| `paused` | Оффер на паузе |
| `archived` | Оффер в архиве |
| `inactive` | Оффер неактивен |

## Цели и ставки

В списке офферов цели и ставки не раскрываются.

Для целей и статистики по goal нужно открыть [Карточку оффера](./03-offer-detail.md).

## Связь оффера с postback

Список офферов помогает выбрать правильный оффер перед проверкой postback, но сам postback URL на этом экране не показан.

Для настройки и проверки postback по офферу используйте:

- [Карточку оффера](./03-offer-detail.md);
- [Postback](./04-postbacks.md).

## Фильтры и поиск

Подтверждены следующие фильтры и инструменты:

- поиск по названию;
- фильтр по статусу;
- пагинация.

Поиск по ID оффера в этом экране не подтверждён отдельным полем.

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Рекламодатель не видит оффер | Проверьте поиск, фильтр по статусу и доступ к нужному офферу |
| Оффер выключен | Проверьте поле `Статус` |
| Цель не отображается | Цели не показаны в списке, откройте карточку оффера |
| Ставки отличаются от договорённостей | Сверьте данные в карточке оффера и уточните условия у менеджера |
| Postback настроен не для того оффера | Сверьте ID оффера в списке, карточке оффера и в вашей postback-настройке |

## Ожидаемый результат

После работы со списком офферов рекламодатель должен:

- найти нужный оффер;
- проверить его статус;
- открыть карточку оффера;
- понять, по какому офферу нужно подключать или проверять postback.
