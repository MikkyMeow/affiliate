# Статистика

Статус: draft

## Назначение

Раздел статистики нужен для детального анализа кликов, конверсий, revenue и payout по выбранному периоду. Здесь рекламодатель проверяет общую картину по офферам и статусам после подключения postback.

## Где находится

Кабинет рекламодателя → Статистика

## Что такое статистика

Это основной аналитический отчёт рекламодателя. В отличие от dashboard, здесь можно задавать период и смотреть разрезы по офферам и статусам.

## Что видит рекламодатель

- фильтр `Дата от`;
- фильтр `Дата до`;
- карточки с метриками;
- таблицу `Разрез по офферам`;
- таблицу `Разрез по статусам`;
- сообщения о пустом периоде или ошибке загрузки.

## Отчёты

В текущей реализации раздел статистики даёт готовый отчёт в двух разрезах:

- по офферам;
- по статусам.

Отдельного конструктора отчётов, группировки по партнёрам или детализации по сырым конверсиям на этом экране не подтверждено.

## Основные метрики

| Метрика | Что означает |
|---|---|
| Клики | Количество кликов за период |
| Конверсии (все) | Общее число конверсий за период |
| Approved | Число подтверждённых конверсий |
| Pending | Число конверсий в ожидании |
| Rejected | Число отклонённых конверсий |
| Revenue pending | Неподтверждённый revenue |
| Revenue approved | Подтверждённый revenue |
| Payout pending | Неподтверждённый payout |
| Payout approved | Подтверждённый payout |

## Основные действия

### Построить отчёт за период

1. Откройте раздел `Статистика`.
2. Заполните `Дата от` и `Дата до`.
3. Нажмите `Применить фильтры`.

**Результат:** отчёт обновится по выбранному периоду.

### Проверить статистику по офферам

1. Откройте блок `Разрез по офферам`.
2. Сравните клики, конверсии, revenue и payout по строкам.
3. При необходимости сверяйте `ID` оффера с разделом [Офферы](./02-offers.md).

**Результат:** вы понимаете, какие офферы дают трафик, конверсии и расходы.

### Проверить статусный разрез

1. Откройте блок `Разрез по статусам`.
2. Сравните конверсии, revenue и payout по каждому статусу.
3. Если есть расхождения, проверьте [Postback](./04-postbacks.md).

**Результат:** вы видите, где именно находится объём конверсий: в pending, approved или rejected.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Date from | Начало периода | Для построения отчёта |
| Date to | Конец периода | Для построения отчёта |
| Оффер | Название оффера и его ID | Для сравнения результатов по офферам |
| Клики | Клики по офферу | Для контроля трафика |
| Конверсии | Все конверсии по офферу | Для контроля возврата результатов |
| Revenue | Сумма revenue | Для оценки расходов |
| Payout | Сумма payout | Для сверки выплат |
| Статус | Статус конверсии | Для анализа качества и этапа обработки |

## Фильтры

Подтверждены:

- `Дата от`;
- `Дата до`.

Фильтры по goal, статусу, офферу, партнёру и GEO на странице статистики рекламодателя не подтверждены.

## Цели

Отдельный разрез по целям на общей странице статистики рекламодателя не подтверждён.

Goal-разрез подтверждён в [Карточке оффера](./03-offer-detail.md).

| `rejected` | Конверсия отклонена |

## Почему данные могут отличаться

- период в вашем отчёте и в другом разделе может отличаться;
- часть конверсий может находиться в `pending`, а не в `approved`;
- postback мог быть отправлен с ошибкой или не по тому `goalId`;
- данные dashboard и statistics отличаются по уровню детализации;
- разные роли видят разные срезы данных;
- часть событий могла не пройти валидацию postback.

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Конверсий меньше, чем во внутренней системе рекламодателя | Проверьте, все ли события отправили postback с корректным `clickId` и `goalId` |
| Расходы не совпадают | Сверьте approved и pending значения, а также период |
| Статистика не обновилась сразу | Проверьте ещё раз через некоторое время и сверяйте с логами postback |
| Разные роли видят разные цифры | Сравнивайте одинаковый период и только те данные, которые относятся к вашему рекламодателю |
| Goal/status передаются некорректно | Проверьте интеграцию postback и блок `Почему postback не засчитался` в [Postback](./04-postbacks.md) |

## Ожидаемый результат

После работы со статистикой рекламодатель должен:

- видеть клики и конверсии по периоду;
- понимать разницу между pending, approved и rejected;
- сверять revenue и payout;
- находить проблемный оффер или статус;
- использовать отчёт как основную точку контроля после отправки postback.
