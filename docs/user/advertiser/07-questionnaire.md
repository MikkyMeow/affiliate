# Анкета

Статус: draft

## Назначение

Анкета нужна для первичного заполнения данных рекламодателя. Пока обязательные ответы не отправлены, доступ к основным разделам платформы может быть ограничен.

## Где находится

Кабинет рекламодателя → Анкета

## Что такое анкета

Это форма с вопросами, которую рекламодатель заполняет после регистрации или при запросе платформы. Набор вопросов настраивается платформой и может отличаться в разных окружениях.

## Зачем заполнять анкету

Анкета нужна, чтобы:

- собрать обязательные сведения о рекламодателе;
- открыть доступ к основным разделам кабинета;
- дать менеджеру и платформе базовый контекст по вашему аккаунту.

## Что видит рекламодатель

- заголовок анкеты;
- описание анкеты, если оно задано;
- предупреждение о необходимости заполнить обязательные поля;
- список полей анкеты;
- ошибки валидации по полям;
- кнопку `Сохранить ответы`.

## Какие данные могут запрашиваться

Точный набор полей зависит от активной анкеты в системе.

Подтверждено, что анкета поддерживает поля типов:

- `text`;
- `textarea`;
- `select`;
- `radio`;
- `checkbox`;
- `multiselect`.

По тестам проекта для рекламодателя встречаются, например:

- вертикаль бренда;
- разрешённые GEO.

Но фиксированный пользовательский набор полей не гарантирован.

## Что может быть недоступно без анкеты

Подтверждено, что незаполненная анкета может блокировать доступ к основным маршрутам кабинета рекламодателя, включая раздел офферов.

## Как заполнить анкету

### Заполнить обязательные поля

1. Откройте раздел `Анкета`.
2. Заполните все поля, отмеченные как `required`.
3. Проверьте, что нет ошибок валидации.
4. Нажмите `Сохранить ответы`.

**Результат:** анкета будет сохранена, а при полном заполнении доступ к кабинету откроется.

### Исправить ошибки в ответах

1. Найдите поле с сообщением об ошибке.
2. Исправьте значение в соответствии с форматом поля.
3. Снова нажмите `Сохранить ответы`.

**Результат:** поле пройдёт проверку, если значение стало корректным.

## Как изменить ответы

Изменение ответов в интерфейсе подтверждено.

Для этого:

1. Откройте раздел `Анкета` повторно.
2. Измените нужные значения.
3. Нажмите `Сохранить ответы`.

**Результат:** система обновит сохранённые ответы.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Вопрос анкеты | Формулировка поля | Когда нужно понять, какую информацию запрашивает платформа |
| Required | Признак обязательного поля | Когда нужно понять, что мешает завершить анкету |
| Варианты выбора | Список доступных значений | Для полей `select`, `radio`, `multiselect` |
| Ошибка поля | Причина, по которой значение не принято | Когда анкета не сохраняется |

## Фильтры и поиск

Фильтры и поиск в анкете не предусмотрены.

## Статусы

Отдельных статусов анкеты на экране не подтверждено.

Практически используются два состояния:

| Статус | Что означает |
|---|---|
| Не заполнена | Обязательные ответы ещё не отправлены |
| Заполнена | Ответы сохранены, обязательные поля закрыты |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Анкета не заполнена | Заполните все поля с пометкой `required` |
| Не все обязательные поля заполнены | Проверьте сообщения об ошибках под полями |
| Нет доступа к офферам | Проверьте, завершена ли анкета |
| Нужно изменить ответы | Откройте анкету повторно и сохраните обновлённые данные |
| Администратор просит дополнить данные | Проверьте, не изменилась ли структура анкеты или обязательные поля |

## Ожидаемый результат

После работы с анкетой рекламодатель должен:

- заполнить обязательные данные;
- снять блокировку с основных разделов кабинета;
- иметь сохранённые и актуальные ответы в профиле.
