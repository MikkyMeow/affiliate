# Профиль

Статус: draft

## Назначение профиля

Профиль нужен для просмотра данных аккаунта рекламодателя, обновления Telegram и смены пароля. Здесь также можно посмотреть сохранённые ответы анкеты и данные ответственного менеджера.

## Где находится

Кабинет рекламодателя → Профиль

## Что видит рекламодатель

- название рекламодателя;
- статус аккаунта;
- public ID;
- ID рекламодателя;
- email аккаунта;
- Telegram;
- даты создания и обновления;
- данные ответственного менеджера;
- блок с ответами анкеты;
- форму смены пароля.

## Личные данные

В профиле подтверждено отображение:

- названия рекламодателя;
- статуса;
- public ID;
- внутреннего ID;
- дат создания и обновления.

Редактирование названия и статуса рекламодателем не подтверждено.

## Настройки профиля

Подтверждено, что рекламодатель может:

- обновлять Telegram;
- смотреть свои ответы анкеты;
- переходить в раздел анкеты для редактирования;
- менять пароль.

Другие пользовательские настройки на этой странице не подтверждены.

## Смена пароля

Смена пароля подтверждена в интерфейсе.

Для этого доступны поля:

- текущий пароль;
- новый пароль;
- подтверждение нового пароля.

Если подтверждение не совпадает с новым паролем, система показывает ошибку.

## Как timezone влияет на данные

В проекте timezone используется для пользовательских данных и статистических расчётов, но в интерфейсе рекламодателя настройка timezone сейчас не выведена отдельным полем.

Практически timezone может влиять на:

- отображение дат;
- границы периода в отчётах;
- восприятие дня в статистике и финансах.

Если отчёты кажутся смещёнными:

- проверьте, в какой timezone вы сравниваете данные;
- уточните текущую timezone аккаунта.

## Основные действия

### Обновить Telegram

1. Откройте раздел `Профиль`.
2. Введите или исправьте Telegram username.
3. Нажмите `Сохранить Telegram`.

**Результат:** контакт Telegram обновится в профиле.

### Посмотреть ответы анкеты

1. Откройте раздел `Профиль`.
2. Пролистайте до блока `Ответы анкеты`.
3. Просмотрите сохранённые ответы.

**Результат:** вы видите, какие данные уже сохранены в анкете.

### Изменить пароль

1. Откройте блок `Смена пароля`.
2. Введите текущий пароль.
3. Введите новый пароль и его подтверждение.
4. Нажмите кнопку сохранения.

**Результат:** пароль будет обновлён, если текущий пароль введён правильно и подтверждение совпадает.

## Основные поля

| Поле | Что означает | Когда используется |
|---|---|---|
| Название | Название аккаунта рекламодателя | Для идентификации аккаунта |
| Статус | Текущее состояние аккаунта | Для понимания доступности работы |
| Public ID | Публичный идентификатор | Для сверки с поддержкой или менеджером |
| ID рекламодателя | Внутренний идентификатор | Для точной сверки в системе |
| Email аккаунта | Email пользователя | Для входа и связи |
| Telegram | Контакт в Telegram | Для связи с менеджером или платформой |
| Ответственный менеджер | Назначенный менеджер | Когда нужно понять, кто сопровождает аккаунт |

## Частые ошибки и ситуации

| Ситуация | Что проверить |
|---|---|
| Неверно отображается дата | Проверьте вопрос с timezone аккаунта |
| Отчёты кажутся смещёнными по дням | Сверьте timezone и период отчёта |
| Нужно изменить личные данные | В интерфейсе подтверждено только обновление Telegram; остальные поля уточняйте отдельно |
| Email изменить нельзя | Это ожидаемо для текущего интерфейса, отдельного поля редактирования нет |
| Пароль меняется в другом разделе | В текущей реализации смена пароля доступна прямо в профиле |

## Ожидаемый результат

После работы с профилем рекламодатель должен:

- видеть основные данные своего аккаунта;
- обновить Telegram при необходимости;
- проверить сохранённые ответы анкеты;
- сменить пароль без обращения в поддержку.
