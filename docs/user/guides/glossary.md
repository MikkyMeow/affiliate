# Глоссарий

Статус: draft

## Назначение

Это словарь основных терминов платформы.

Он помогает быстрее понять, как называются ключевые сущности и действия в повседневной работе.

## Термины

### CPA

CPA - это модель, при которой результат оценивается по целевому действию.

### Оффер

Оффер - это предложение рекламодателя, которое партнёры могут продвигать.

### Цель оффера

Цель оффера - это конкретное действие пользователя, за которое может начисляться результат.

### Партнёр / Affiliate

Партнёр - это участник, который приводит трафик на офферы.

### Рекламодатель / Advertiser

Рекламодатель - это участник, который принимает трафик и сообщает платформе о результатах.

### Tracking-ссылка

Tracking-ссылка - это ссылка, по которой партнёр отправляет трафик через платформу.

### Клик

Клик - это переход пользователя по tracking-ссылке.

### Click ID

Click ID - это уникальный идентификатор клика.

### Canonical Click ID

Canonical Click ID - это основной идентификатор клика, который используется для связи клика и конверсии.

### Конверсия

Конверсия - это целевое действие пользователя, которое было зафиксировано платформой.

### Postback / Постбэк

Postback - это запрос от рекламодателя в платформу с информацией о конверсии.

### Postback URL

Postback URL - это адрес, на который рекламодатель отправляет postback.

### Goal / Цель

Goal - это идентификатор или название цели оффера.

### Payout

Payout - это сумма выплаты партнёру за конверсию.

### Revenue

Revenue - это сумма дохода от рекламодателя за конверсию.

### Статус конверсии

Статус конверсии - это состояние конверсии, например `pending`, `approved`, `rejected`.

### Гео / GEO

Гео - это страна или регион пользователя, по которым может ограничиваться доступность оффера.

### Redirect URL

Redirect URL - это адрес, на который пользователь отправляется после фиксации клика.

### Доступ к офферу

Доступ к офферу - это разрешение партнёру работать с конкретным оффером.

### Анкета

Анкета - это форма, которую пользователь должен заполнить для работы с платформой или отдельными функциями.

### Корректировка

Корректировка - это ручное или импортированное изменение данных по кликам, конверсиям или статистике.

### Статистика

Статистика - это сводные данные по кликам, конверсиям, выплатам, доходам и другим метрикам.

### Аудит

Аудит - это журнал действий пользователей в платформе.

### Менеджер

Менеджер - это пользователь, который помогает администратору вести партнёров, рекламодателей и рабочие процессы.
